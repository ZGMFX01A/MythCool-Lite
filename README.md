# Myth.Cool Lite

专为 VK 带屏水冷设计的轻量副屏播放工具。

## 为什么做它

原版 Myth.Cool 常驻进程多、占用资源高。Myth.Cool Lite 只保留副屏播放所需功能，在实际测试中明显降低了电脑负载：

| 项目 | 原版 Myth.Cool | Myth.Cool Lite |
| --- | ---: | ---: |
| 进程数 | 9 | 4 |
| 内存占用 | 864 MB | 184 MB |
| CPU 占用（单核） | 26.3% | 3.2% |

## 下载

前往 [GitHub Releases](https://github.com/ZGMFX01A/MythCool-Lite/releases) 下载单体程序 `MythCoolLite.exe`，无需安装，也不提供压缩包或安装包。

## 适用范围

仅适用于 VK 带屏、且屏幕本身没有存储芯片和独立播放能力的水冷设备。当前验证设备为 `MC360`，分辨率为 640×480。

使用前请先关闭原版 Myth.Cool。
